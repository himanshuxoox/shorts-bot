Shorts Bot

A personal automation tool for my own YouTube channel.

Shorts Bot generates original physics-simulation videos entirely with code (Python, cairo, ffmpeg) and uploads them to my own YouTube channel on a schedule, using the YouTube Data API.

  • It only uploads videos to the channel owned by the developer.
  • It does not read, collect or store data about other YouTube users.
  • It is not offered as a service to the public.

Uses YouTube API Services

Shorts Bot uses the YouTube Data API (YouTube API Services) only to upload videos to my own channel, Orbit Escape.

Privacy Policy

Shorts Bot ("the app") is a personal tool operated by Himanshu Singh for uploading his own videos to his own YouTube channel.

What data the app accesses

The app requests one Google permission, https://www.googleapis.com/auth/youtube.upload. It is used only to upload videos, and to set their titles, descriptions, tags and schedule, on the developer's own YouTube channel.

What data is stored

The app stores one OAuth refresh token for the developer's own Google account. It is kept as an encrypted GitHub Actions secret. The app does not collect, store, sell or share personal data of any other user.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account → Security → Third-party access.
